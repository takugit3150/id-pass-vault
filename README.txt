ID PASS Vault Pro

【使い方】
1. このフォルダ一式をHTTPS対応のWebサーバーへアップロードします。
2. Safariで公開URLを開きます。
3. 共有 → ホーム画面に追加、でアプリのように利用できます。
4. 初回はマスターパスワードで保管庫を作成します。
5. 管理 → Face IDクイック解除を設定、でFace IDを有効にします。

【iCloud】
管理 → iCloud Driveへバックアップ → 共有画面で「ファイルに保存」→ iCloud Drive。
別端末では、同じ公開URLを開き、同じマスターパスワードで保管庫を作成後、
管理 → 暗号化バックアップを読み込む、から復元します。

【重要】
・マスターパスワードを忘れると復元できません。
・Face IDはHTTPS環境が必須です。
・データはブラウザ内に暗号化保存されます。
・Safariの履歴／Webサイトデータを削除すると端末内データも消えるため、バックアップしてください。
・Face IDクイック解除はSafariのWebAuthnを利用した補助機能で、Apple純正「パスワード」アプリと同一のセキュリティ構造ではありません。
